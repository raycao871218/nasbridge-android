# 麻雀会

Android display name: **麻雀会**. Its NAS backend is **鸟巢**. Both belong to the same crayon visual family as **咕咕咕** (message-redirect).

Use warm paper `#FCF6E8`, cream cards `#FFFCF4`, ink `#3B3A49`, muted text `#706B75`, dusty-blue wax `#BACCEB`, peach selection `#F0C8AA`, and coral strokes `#D48D79`. Status colors remain dark enough to read on paper. Video surfaces retain their dark backgrounds and light text.

`CrayonTexture` is adapted from message-redirect's cached paper/wax tile renderer. `CrayonDrawable` and its paper, wax, and peach variants draw gently irregular outlines without changing view bounds or hit targets. Text remains untextured. The sparrow is a native vector with a brown head, cream belly, cheek patch, orange beak, and short pigment strokes. No image generation or external artwork is used.

Keep package ID `com.nas.dashboard`, saved preferences, API service identity `NASBridge`, and configuration schema IDs unchanged. These are compatibility identifiers, not display names.
